# MU Reborn - Downloads

Instalador oficial do MU Reborn (launcher + jogo em portugues).

Baixe pela pagina de downloads do site: https://mu-reborn.vercel.app/downloads

Confira o SHA-256 publicado no site antes de executar:

```powershell
Get-FileHash .\Instalador-MU-Reborn.exe -Algorithm SHA256
```
